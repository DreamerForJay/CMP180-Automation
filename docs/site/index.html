Installation

兩種安裝方式

只要看介面、做教學或產生示範資料，可攜版就夠了。要接實機或修改程式，才需要原始碼環境。

給沒有開發環境的使用者。解壓縮後雙擊即可，預設不會送出任何射頻命令。

  1. 下載 CMP180-Windows-x64.zip，完整解壓縮到可寫入的資料夾。
  2. 雙擊資料夾內的 CMP180.exe。請保留整個資料夾，不要只複製執行檔，也不要直接從壓縮檔內執行。
  3. 瀏覽器會自動開啟 http://127.0.0.1:8765；沒有開啟時手動輸入該網址。 
    # 埠號被占用時改用其他埠
CMP180.exe --port 8766
  4. 結束時回到主控台按 Ctrl+C。關閉瀏覽器分頁不會停止工作站。
  5. 要接實機時，先讀完射頻安全規則再加上參數啟動。 
    CMP180.exe --hardware

開發、接實機、跑測試與重新打包都走這條路徑。

  1. 取得原始碼並建立虛擬環境。 
    git clone https://github.com/DreamerForJay/CMP180-Automation.git
Set-Location CMP180-Automation
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
  2. 安裝相依套件。hardware 只有要接實機時需要。 
    python -m pip install -e ".[dev,hardware]"
  3. 驗證設定檔。兩個指令都顯示 OK 才代表格式與欄位通過。 
    python -m cmp180_evm validate-config configs\instrument.example.yaml
python -m cmp180_evm validate-config configs\wlan_baseline.example.yaml
  4. 以模擬模式啟動網頁工作站。 
    python -m cmp180_evm.web --demo-only
  5. 實機模式只能綁定 loopback，且仍須通過頁面上的安全確認。 
    python -m cmp180_evm.web --host 127.0.0.1 --enable-hardware

單次量測

七階段狀態機。任何例外、逾時或取消都保證先停止量測再關閉射頻。

頻率掃描

由多次完整單次量測組成，每點之間完成收尾；失敗時保留已成功的點。

400 MHz – 8 GHz · dwell 0.01–10 s

MCS 掃描

RF safety · 不可協商

開啟射頻之前

  • 軟體不會替你確認硬體。接線、衰減量與分析儀最大輸入準位由操作員負責確認。
  • 預設唯讀查詢。FETCh 只讀取已保存結果；READ 與 INITiate 會啟動量測。
  • 未經明確要求不得重設儀器或工作區。
  • 所有射頻流程都保證收尾。成功、錯誤、逾時、取消都會嘗試停止／中止並關閉射頻。
  • 實機模式只能綁定 loopback。目前沒有身分驗證與權限控管，不得暴露到內網。
  • 模擬結果不是實機證據。模擬、預覽與離線分析都不能作為合規宣稱。
