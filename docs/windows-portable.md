# Windows 可攜版使用說明

本文件說明如何把 CMP180 網頁工作站交給沒有 Python 環境的 Windows 使用者，以及如何在開發機重新建立發布檔。

## 發布內容

發布檔是 `dist/CMP180-Windows-x64.zip`，適用 Windows 10／11 64 位元。壓縮檔包含執行檔、網頁靜態資源、範例設定、必要文件與程式相依檔案；不包含私人設定、開發機量測紀錄、測試快取或授權金鑰。

## 接收者啟動

1. 將壓縮檔完整解壓縮到可寫入的資料夾。
2. 雙擊資料夾內的 `CMP180.exe`。
3. 等待主控台顯示網址，瀏覽器通常會自動開啟 `http://127.0.0.1:8765`。
4. 若瀏覽器沒有開啟，手動輸入該網址。
5. 完成操作後回到主控台按 Ctrl+C；關閉瀏覽器不會停止工作站。

請保留整個資料夾，不要只複製執行檔，也不要直接從壓縮檔內執行。若埠號已被占用，可在主控台執行 `CMP180.exe --port 8766`。

## 模擬模式與實機模式

雙擊啟動預設為模擬模式，不建立 CMP180 連線、不送出射頻命令，適合展示、訓練與產生教學資料。模擬輸出會保存 `source=mock` 或 `simulated=true` 標記，不能作為實機證據。

實機操作前必須閱讀[硬體量測標準作業程序](hardware-test-sop.md)，確認接線、衰減、頻率、頻寬、功率、DUT 與分析儀輸入上限，再以 `CMP180.exe --hardware` 啟動。此參數只開啟既有實機入口與安全閘門，不會替操作員確認硬體，也不會放寬核准條件。第一次跨電腦使用仍要由操作員確認網路與相容的儀器傳輸環境。

## 輸出資料

量測與模擬結果寫入執行檔旁的 `output/`。每個執行資料夾通常包含表格結果、結構化資料、設定快照、原始回應、錯誤佇列、圖形與有效性摘要。請保留完整資料夾，方便追蹤來源與最終射頻狀態。

## 重新打包

開發機需要 Python 3.11 以上與建置相依套件。先在專案虛擬環境安裝建置、測試與實機套件，再執行：

```powershell
.venv\Scripts\python.exe scripts\build_windows.py
```

產物為 `dist/CMP180/CMP180.exe` 與 `dist/CMP180-Windows-x64.zip`。建置工具會使用 `CMP180.spec` 收錄正式網頁資源與必要的動態圖形後端，並只複製範例設定與發布文件。

## 發布前驗證

```powershell
.venv\Scripts\python.exe scripts\verify_windows.py
```

驗證工具會把壓縮檔解壓到含中文的暫存路徑，從不同工作目錄啟動執行檔，檢查首頁、靜態資源、能力設定、模擬鎖定，以及表格與圖形匯出。發布前另應執行完整測試、兩份設定驗證與 `git diff --check`。

本可攜版不包含新的實機射頻驗證。若要宣稱硬體能力，必須另附核准設定、原始回應、錯誤佇列、最終射頻狀態與日期化實機證據。
