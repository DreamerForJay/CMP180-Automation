01
啟動 Demo 控制台
不連線 CMP180、不送 SCPI、不產生 RF；適合現在查看與練習。

          
PowerShell
PS .\.venv\Scripts\Activate.ps1
PS python -m cmp180_evm.web --host 127.0.0.1 --port 8765

          
開啟瀏覽器http://127.0.0.1:8765

        

        

          
02
檢查設定檔
只驗證 YAML 欄位與安全設定，不會接觸儀器。

          
PowerShell
PS python -m cmp180_evm validate-config configs\instrument.example.yaml
PS python -m cmp180_evm validate-config configs\wlan_baseline.example.yaml

          
正確輸出OK (instrument) · OK (wlan_baseline)

        

        

          
03
唯讀連線檢查
讀取 IDN、Options 與 Error Queue，不啟動量測、不開 RF。

          
PowerShell
PS python -m cmp180_evm test-connection --instrument-config configs\instrument.example.yaml

          
供電不穩時只執行唯讀檢查，不要啟用硬體 Web 模式。

        

        

          
04
實機模式（暫停）
只有供電穩定、接線確認、操作員在場且完成授權後才能使用。

          
PowerShell
# 暫停使用 / HOLD
PS python -m cmp180_evm.web --enable-hardware

          
RF HOLD目前儀器供電不穩，禁止執行。

        

      

      
?
結果會存在哪裡？
每次執行會建立獨立 output Run 資料夾。到「量測紀錄」按「開啟資料夾」，或在「結果與圖表」開啟 HTML、CSV、JSON。
!
何時必須停止？
看到 INV、RF 狀態不明、量測逾時、SCPI Error、接線異動或供電異常時，立即停止並確認 RF OFF。
