CAPABILITIES

量測與資料分析功能

整合量測設定、執行狀態、結果檢視與檔案管理。CMsquares 保留作為儀器設定探索與除錯工具。

RF-01

實機量測控制

依所選流程檢查頻率、頻寬、功率與接線確認；操作員完成最後確認後執行量測。

RF-02

頻率與功率掃描

顯示逐點進度並支援取消。WLAN 掃描遇關鍵結果無效、儀器或收尾錯誤時停止後續點位，保留已取得的結果。

DSP-03

WLAN EVM 分析

檢視 EVM、功率與頻率誤差，支援互動圖表及圖檔匯出；無效結果以 INVALID 標示。

DATA-04

歷史量測比較

搜尋與篩選量測紀錄，選取 2–8 筆進行疊圖比較，調整曲線樣式並匯出圖表。

CAL-05

路徑損耗資料管理

匯入參考讀值並建立校正草稿。正式套用須確認器材、參考面、有效範圍與核准狀態。

OPS-06

量測檔案與執行紀錄

依量測流程保存結果、設定與執行資訊；實機結果另記錄原始回應及 RF 收尾狀態。可用檔案以該筆紀錄為準。

STANDARD WORKFLOW
